# 案例：圈圈粉（WordPress 博主资源站 → 订阅源）

> 站点：https://www.quanquanfen.com （WordPress 7.x + 主题 wp-theme-aituse）
> 成品：`圈圈粉订阅源.json`（同目录）
> 技术要点首次沉淀于 `../rss-source-spec.md`。

## 站点特征

- 文章流形态：首页 = 帖子更新列表；每篇帖子 = 图集（多个 `<figure>`）或视频（`<video poster>`）。
- 帖子标题格式：`博主名 | 日期 类型 | 文案`。
- 博主 = tag（`/tags/{slug}/`），tag 页 = 该博主帖子列表（可分页 `/tags/{slug}/page/{n}`）。
- 分类归档 11 个：`/`（最新）、`/daoyuqudao/`、`/weimiquan/`、`/gengxinyuan1-3/`、`/wmtiefenkongjian/`、`/myukongjian/`、`/huanyuxingqiu/`、`/wmsiyuquan/`、`/wmyutangquan/`。
- 站内搜索 `?s=关键词` 搜帖子标题（含博主名 → 可当"搜博主"用）。
- 老帖含推广文案（【本站免费分享…】【温馨提示…】、`<p>圈子：#xxx</p>`）。
- 媒体 CDN `img.ziyuanquancdn.com` 支持 CORS（`Access-Control-Allow-Origin: *`）→ 视频可内嵌播放。
- WordPress REST API 可用：`/wp-json/wp/v2/tags?search=`（博主）、`/wp-json/wp/v2/posts?tags=`（帖子）。

## 最终规则（可直接参照）

| 字段 | 值 |
|------|-----|
| `sourceUrl` | `https://www.quanquanfen.com/page/{{page}}` |
| `sortUrl` | 11 个静态分类，`名::https://www.quanquanfen.com/{cat}/page/{{page}}` |
| `searchUrl` | `https://www.quanquanfen.com/page/{{page}}?s={{key}}` |
| `ruleArticles` | `article.post-card:not(.post-sticky)` |
| `ruleTitle` | `.post-title a@text` |
| `rulePubDate` | `.post-meta .meta-item.0@text` |
| `ruleImage` | `<js>` 视频取 `video@poster`，图集取 `.post-gallery img@src` 首张 `</js>` |
| `ruleLink` | `.post-title a@href` |
| `ruleNextPage` | `page` |
| `ruleContent` | `<js>` 净化推广文案 + 构建深色主题完整 HTML（video 内嵌播放）`</js>` |
| `ruleDescription` | **不填**（填了打开文章只显示摘要） |

## 迭代史（每个坑都值得记）

1. **格式误判**：用户说"制作订阅源"，首轮做成了书源（bookSource 格式）→ 整轮返工。**教训：字段名 sourceXxx vs bookSourceXxx 先分清。**
2. **导入格式**：首版给数组 `[{...}]`，编辑界面导入报 `Expected BEGIN_OBJECT but was BEGIN_ARRAY` → 编辑界面要单对象 `{}`。
3. **ruleDescription 陷阱**：填了描述 → 打开文章只显示摘要文字，手动刷新才加载正文（源码 `ReadRssViewModel` 行为）→ 删除该字段解决。
4. **封面空白**：`ruleImage: .post-gallery img@src` 在图片帖命中 23 张 → `\n` 拼接非法 URL → 封面空白；改 `<js>` 取首图解决。
5. **视频不能播**：`ruleContent` 把 `<video>` 转成"封面图+文字直链" → 用户要内嵌播放；改保留 `<video controls>` + 构建完整 HTML 页面解决。
6. **动态分类转义坑**：sortUrl JS 里 `out.join("\n")` 经 JSON 序列化后 `\n` 变真实换行 → JS 语法错误；改 `String.fromCharCode(10)`。
7. **最终形态**：用户要求"博主不放进分类导航，只保留搜索" → sortUrl 还原为 11 个纯静态分类 + searchUrl 保留。

## 验证记录

- 订阅源无官方验证器 → 用 harness 转书源跑 `verify_source.py`：封面/正文规则实测通过。
- Python 脚本模拟 `RssParserByRule`：列表 12 条、字段命中、净化生效、翻页正常、空搜索兼容。
- Node `eval` 跑 sortUrl JS：41 条目（11 分类 + 30 博主）输出正常（后因需求改为纯静态）。
- 用户 App 实测确认：分类、搜索、图片、视频内嵌播放均正常。
